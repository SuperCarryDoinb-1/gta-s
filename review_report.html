三条核心判断

① 骨架已成，可以直接往上堆内容。
回调解耦 + 对象池 + 固定步长插值三条约定贯彻得很干净，新增一个玩法系统的边际成本极低——这是原型阶段最值钱的资产。

② 玩法循环缺"上升螺旋"。
主线六步后进入自由模式，此时玩家只剩"开出租赚钱"和"撞人捡钱"两个平循环，钱没有值得追求的出口，动机在 20 分钟内归零。

③ 风险最高的不是性能，是"城市不像活的"。
26 个行人 + 6 辆车 + 装饰性红绿灯，街道空旷且无秩序感。密度与规则是开放世界可信度的地基。

④ 帧循环与解耦约定GAME LOOP & DECOUPLING

帧循环时序

fixedUpdate(dt=1/60) // 固定步长，最多补 5 步
 ├ 角色陷地/坠落兜底（按分区判高度）
 ├ beginStep ×（角色 / 4 自有载具） ← 记录插值起点
 ├ 行人 · 交通 · 通缉 AI 决策 → 写物理输入
 ├ playerManager.fixedUpdate（驾驶输入 / 撞击伤害）
 ├ physics.step() ← 计时进 HUD physMs
 └ endStep ×（全体） ← 采样物理结果为插值终点

update(dt, alpha) // 每帧，alpha = 两步之间插值系数
 ├ 上下车音效沿边触发
 ├ syncVisual(alpha) ×（全体） ← 高刷屏防抖关键
 ├ 骑手贴装 + 双手 IK 握把
 ├ Story / Weapons / Shops / TaxiJobs / Pickups 轮询
 ├ 天气 → 湿度 → 路面材质 / 音频 / 辉光
 ├ 昼夜 → 车灯 / 路灯 / bloom（0.05 + 夜×0.24 + 夜雨×0.12）
 ├ chunkManager.update（流式加载 / 门 / 水波 / 信号灯）
 ├ 音频总线（引擎 / 警笛 / 喇叭 / 胎啸 / 脚步）
 └ HUD + 小地图重绘 + input.endFrame
任何 60Hz 直读位姿在 144Hz 屏上都会抖——syncVisual(alpha) 的存在是这个项目画面稳定的根因。

⑤ 玩法解构GAMEPLAY ANATOMY

核心循环

作案抢车 · 开枪 · 撞人 · 爆炸 · 袭警
↓ 犯罪上报 heat +
通缉升级 1★→3★警车追击 → 警察下车围捕 → 更多警力/更准枪法
↓ 三条出口
断视线（免费） · 下海（免费） · 喷漆店（$200）建筑真实遮挡射线 · 警察不下水 · Pay'n'Spray 立即清零
↓ 脱身 / 或被打倒
收益结算掉落现金 · 出租车费 · 或医院复活 −$100
↓ 补给
消费弹药 · 修车 · 洗通缉
↺ 回到作案
循环诊断：这是一个闭合但不上升的循环。收益只用于维持下一次循环的成本，玩家在第 3 圈之后不会变强、不解锁任何东西、也没有新目标——这是长期留存评分只有 1.8 的直接原因。

⑥ 设计评估CRITIQUE

做得好的地方

  • 固定步长 + 视觉插值贯彻到每个实体，高刷屏无抖动——很多同类原型栽在这。
  • 回调解耦 + main 单点接线：11 条回调是全部耦合面，新系统接入成本极低。
  • 全对象池（行人/车/警力/曳光/现金/烟火），连 setLinvel 参数对象都复用，无 GC 掉帧。
  • "载具即插槽"：抢车 = 主车瞬移换装，O(1) 所有权，省掉一整套载具管理复杂度。
  • 通缉的三条出口有明确成本梯度（断视线免费但难 / 下海免费但离场 / 喷漆 $200 但即时），是教科书式的玩家选择设计。
  • 警察跑速 5.2 < 玩家 9 的刻意留白，让"逃"永远是可行的——正确的挫败感控制。
  • 物理参数有实测依据（悬挂阻尼比、摩托把端坐标取自顶点实测），不是拍脑袋调的。
  • 碰撞体增删限速 20 ops/frame：把流式加载的顿挫摊平，是真正踩过坑才会写的代码。
  • ?autotest 帧驱动冒烟测试：用帧计数而非定时器，规避后台标签页 rAF 暂停误判。
  • 素材许可清晰（ASSETS.md 全部 CC0/CC-BY 并登记署名），没有法务雷。

问题清单（按严重度）

  • 严重 长期动机断崖：Story.ts 进入 done 后无任何目标产出，剩余循环全是平的。
  • 严重 金钱无出口：支出全为消耗品，无购车/房产/升级，攒钱无意义（见上表）。
  • 严重 无存档：全项目零 localStorage，刷新即丢金钱/弹药/剧情进度。
  • 高 城市密度不足：Pedestrians COUNT=26、Traffic CAR_COUNT=6，街道空旷，"活的城市"感缺失。
  • 高 红绿灯是纯装饰：updateCitySignals 全城同步变色，AI 车不停、玩家闯红灯无后果，秩序感为零。
  • 高 死亡惩罚过轻反成捷径：$100 换"清空通缉 + 满血"，3★ 时故意送死比逃跑更划算，破坏通缉张力。
  • 高 步行战斗单薄：无瞄准态/掩体/近战/锁定，手枪与机枪差异仅在射速，敌人只有警察一种。
  • 高 通缉上限 3★ 且警力只有两种单位：无路障、无直升机、无警犬，3★ 后压力不再上升。
  • 中 行人只有 3 态（walk/flee/down），无坐/交谈/进出店，人群像跑步机上的模型。
  • 中 流式半径 240m 的连锁副作用：远处载具会踩空，只能靠 setStashed 规避，限制了"把车停在远处"这类基本自由。
  • 中 导航只有 HUD 箭头 + 小地图，无全屏地图与自定义航点，玩家无法规划路线。
  • 中 输入仅键鼠：无手柄、无触屏，浏览器游戏放弃了一半潜在设备。
  • 中 音乐无动态层次：通缉升级不改配乐，最容易做的情绪杠杆没用上。
  • 中 抢来的车无法保留：插槽模型的代价——玩家收集欲无处安放。

⑦ 优化建议OPTIMIZATION

工作量标注：S ≤半天 M 1–3 天 L 1 周+

性能 — 目标：把行人密度从 26 提到 80+ 而不掉帧

⑧ 新玩法提案NEW FEATURES

按"投入产出比"排序。P0 三项合力可把游戏时长从 ~20 分钟拉到 2 小时以上。

P0 — 先修动机断崖（合计约 1 周）

P0

存档系统

S
localStorage 持久化：金钱、弹药、剧情状态、已解锁项、车库、统计数据。这是所有长线玩法的前置条件——没有存档，任何"养成"设计都无意义。菜单加"继续 / 新游戏"。
落点：新增 core/SaveGame.ts，在 Health / Weapons / Story 暴露 serialize()·restore()，main.ts 接线
P0

车库与购车（金钱出口）

M
新增车行光柱：花钱解锁车型（跑车 $8k / SUV $5k / 摩托 $3k / 快艇 $15k），存进车库；任意车库点可召唤已拥有载具。抢来的车开进车库可"洗白入库"（收费）。让抢车、出租、赏金全部有了终点。
落点：gameplay/Garage.ts（复用 Shops 的光柱 + 按键交互模板），配合 Vehicle.setCarType 与存档
P0

支线任务生成器

M
把 TaxiJobs 泛化成 JobSystem，四类程序化任务共用"光柱 + 导航 + 计时 + 结算"：
· 快递：限时送包裹，超时罚款
· 护送：保护 NPC 车不被打爆
· 追击：追上并逼停标记车（复用 markCourier）
· 逃脱：接单即 2★，坚持 90 秒
难度与报酬随完成次数上升，形成上升螺旋。
落点：gameplay/JobSystem.ts，抽取 TaxiJobs 的状态机骨架；Beacon / HUD 零改动即可复用
P0

技能 / 声望成长

S
四条经验轴：驾驶（完成任务）、射击（命中）、耐力（跑动 / 游泳）、恶名（犯罪）。等级提升给可感知的小加成——最高血量、回血速度、载具抓地、通缉衰减速度。恶名等级则反向提高警方响应强度，形成风险-收益的自平衡。
落点：gameplay/Progression.ts，消费现有 11 条回调即可，无需改动实体层

P1 — 加深核心体验（合计 2–3 周）

P1

帮派与地盘

L
码头帮已在主线登场却在通关后消失。给它 3 个据点：清剿据点 → 解锁该区域的车库折扣 / 任务点 / 藏身处；据点会周期性"反扑"。敌对 NPC 可直接复用 Wanted 的步行警察 AI（视线检测、下车围捕、血条都是现成的），换模型与阵营判定即可。
落点：gameplay/Gangs.ts，把 Wanted 的警察单元抽成通用 ArmedUnit
P1

竞速赛事

M
路网是规则网格，天然适合程序化生成环线：随机取 6–10 个路口作 checkpoint，玩家下注、AI 车参赛、名次结算。夜间 / 雨天开专属高赔率场次，把已有的天气系统变成玩法变量。
落点：gameplay/Races.ts，复用 City.snapToRoad / advanceOnRoad 生成路线与 AI 对手
P1

通缉 4★–5★ 与新警力

M
上限提到 5★，逐级引入：3★ 路障（路口生成静态警车墙）、4★ 警用直升机（探照灯破解"断视线"，逼玩家进室内或下海）、5★ 装甲车。每一级都必须让原有的逃脱手段之一失效，这样升星才是真正的压力升级。
落点：Wanted.ts（COUNT_BY_STARS 扩表 + 新单位类型），直升机需新增简易飞行体
P1

抢劫玩法（室内利用）

M
City 已生成"三层可进塔楼 + 楼梯高度场"，这套昂贵的资产目前没有玩法承接。加入：便利店 / 银行抢劫——进店举枪 → 计时收银 → 警报触发 2★ → 带钱逃脱。天然复用现有全部系统。
落点：gameplay/Robbery.ts + City.ts 标记可抢劫室内点
P1

全屏地图与航点

M
M 键打开全城地图：已探索区域、商店 / 车库 / 任务点图标、自定义航点（在小地图与 HUD 导航中生效）。开放世界没有地图，玩家就无法产生"计划"，而计划是沉浸感的来源。
落点：ui/MapScreen.ts，数据源与 Minimap 共用
P1

手柄支持

S
Gamepad API 映射到现有 Input 抽象层（该层已有 debugHold 注入接口，扩展成本很低）。驾驶体验对扳机键的模拟量输入尤其敏感，收益立竿见影。
落点：core/Input.ts 内部扩展，上层零改动

P2 — 长期方向

P2

多人联机（2–8 人自由城）

L
固定步长循环 + 实体 beginStep/endStep 的结构对状态同步很友好：位置走快照插值，载具走权威端 + 客户端预测。先做"共享城市 + 竞速 / 追捕小游戏"，不做全物理同步。
落点：新增 net/ 层；main.ts 的接线表即是需要同步的事件清单
P2

空中载具

L
直升机 / 小飞机。需要先解决流式加载半径（240m）——高空视野会直接暴露世界边界，需配套远景 impostor 城市剪影。
落点：Vehicle.ts 新增 HELI_SPEC + ChunkManager 远景层
P2

房产与被动收入

L
购买安全屋（存档点 + 载具停放 + 换装）与生意（洗车行 / 夜店，按时产出被动收入，可被敌对帮派袭击）。这是把金钱转化为长期目标的终局设计。
落点：gameplay/Property.ts，依赖 P0 存档与 P1 帮派
P2

移动端 / 触屏

M
虚拟摇杆 + 情境按钮，配合已有的自适应画质分档。浏览器游戏最大的分发优势就是"点开就玩"，放弃移动端等于放弃一半流量。
落点：core/Input.ts + ui/TouchControls.ts

⑨ 建议路线图ROADMAP

阶段一 · 让人愿意玩第二次

约 1 周 · 目标：单局时长 20min → 2h

  • 存档系统（P0）
  • 车库与购车（P0）
  • 支线任务生成器（P0）
  • 死亡惩罚重构 + 通缉搜索圈
  • 红绿灯生效 + 路边停放车可抢

验收：通关主线后仍有明确的下一个目标；金钱曲线可持续上升。

阶段二 · 让世界立得住

约 2–3 周 · 目标：可信度与压力曲线

  • 行人渲染降本 → 密度提到 80+
  • 通缉 4★–5★ + 路障 / 直升机
  • 帮派与地盘、抢劫玩法
  • 瞄准态 + 武器差异化 + 车型分级
  • 全屏地图、手柄、动态配乐

验收：3★ 以上逃脱需要真正的路线规划；街道任意时刻都有人和车。

阶段三 · 扩张

1 个月+ · 目标：分发与留存

  • 竞速赛事 + 房产被动收入
  • 多人联机（先小游戏后自由城）
  • 空中载具 + 远景城市剪影
  • 移动端触屏
  • 资源压缩（Draco / KTX2）降首屏

验收：首屏 <5s；有可分享的社交场景。

最后一句评审意见：这个项目的技术地基比绝大多数浏览器开放世界原型都扎实——真正欠缺的不是代码，是让玩家想要下一个东西的设计。阶段一的三项 P0（存档 / 购车 / 任务生成器）互相咬合，是投入产出比最高的一次改动，建议优先。
