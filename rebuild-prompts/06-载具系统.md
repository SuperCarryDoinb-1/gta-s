### 构造 `(scene, physics, spawn, carLib, spec=CAR_SPEC, customModel=null)`
dynamic 底盘(CCD 开;upright 时 enabledRotations(false,true,false));cuboid 碰撞体 + 手动 `setMassProperties`(质量 spec.mass、质心 (0,comDrop,0)、盒惯量 mass/12 公式);roofHull 时按 `colliderBoxes().cabin` 挂密度 0 座舱盒 @(0, cabin.cy+groundOffset, cabin.cz);vehicleController 逐轮 `addWheel(锚点, (0,-1,0), (-1,0,0), suspRest, wheelRadius)` 并设全部悬挂参数与 SideFriction 0.85;视觉:车模(groundOffset 下移)/四盏灯/两聚光灯/非 hideWheels 建轮。

### fixedUpdate(dt, drive{throttle,steer,brake}) —— physics.step 之前
```
speedMs = forwardSpeed()   // 手动投影:车头前向量 fx=2(qx·qz+qw·qy), fy=2(qy·qz-qw·qx), fz=1-2(qx²+qy²)
// 保险丝:非有限或 y<-6 → 复位 (lastGood.x, 2.5, z),清速度,重置插值端点,return
// 水面浮航:chunkZone(round(x/96))=='ocean' 且 y<0.3 时
//   冲量 (fx·throttle·thrust - vx·1.1, (0.15-y)·14 - vy·5 + 9.81, fz·throttle·thrust - vz·1.1)·mass·dt
//   扭矩 (-avx·0.8, steer·turn-avy·1.5, -avz·0.8)·mass·dt;wrecked 时 thrust=0
// 转向:steerLimit = steerMax/(1+|speed|/steerFalloff);steering 阻尼逼近(1-exp(-10dt))
// 油门刹车仲裁:
//   throttle>0:speed<-0.5 → 全刹;否则 engineForce=throttle·engine·max(0,1-speed/topSpeed)
//   throttle<0:speed>0.5 → 全刹;否则倒车 engineForce=throttle·engine·0.5·max(0,1-|speed|/8)
//   无油门 → IDLE_BRAKE=3;wrecked → engineForce=0
// 每轮:前轮 setWheelSteering;后轮 setWheelEngineForce;
//   brake = 手刹?(前轮0/后轮 handbrake):serviceBrake
//   侧摩擦 = (手刹且后轮)?0.35:0.85     ← 漂移核心
// 刹车灯 emissive = (手刹或 serviceBrake>=brake)?2.2:0.15
// 撞击:impactDv = max(0, prevForward-speedMs);>6 → damage((impactDv-6)*2.5)
controller.updateVehicle(dt, …, filter 排除自身底盘与座舱盒)
```

### 其他方法
`beginStep/endStep`:插值端点=pos+quat+每轮悬挂长+自转+转向角(**全部插值,直读必抖**)。
`syncVisual(alpha)`:pos lerp、quat slerp;lean 时 `carGroup.rotation.z = -插值steer·min(|prevForward|/12,1)·0.8`(摩托压弯);轮 pivot.y=wheelY-插值susp,前轮 rotation.y=steer,rotation.x=插值spin。
`visualHeadingYaw`(插值后 mesh 四元数求 atan2(fx,fz))、`visualLean`、`getPosition/getQuaternion/getVisualPosition/getLinvel`、`get speedKmh`(forwardSpeed*3.6 带符号)。
`get carType`/`setCarType(type)`(换模型+refreshRoofHull)。
`get wrecked`;`damage(n)`(wrecked 或 n<=0 忽略;归零→isWrecked=true+onExploded);`repair()`(100/false)。
`updateFx(dt)`:发射率 stashed 0/wrecked 14/<25 火 10/<50 烟 5/否则 0;粒子 life 递减、scale=0.7+k*1.8、opacity=(1-k)*0.55;emitFx:fire=condition<25 且 rand<0.45,火 max0.4 色 0xff7a2a Additive/烟 max1.1 色 0x555555,vy 火 1.0+r*0.6/烟 1.4+r*0.7,vx/vz=(r-0.5)*0.6,发射点引擎盖 ((r-0.5)*0.5, 0.55, half.z*0.55) 变换到世界;池上限 14,无空槽顶掉最短命。
`get stashed`/`setStashed(on)`(mesh 隐藏+刚体 setEnabled);`teleportTo(x,z,yaw,y=0.9)`(瞬移+清动力学+重置端点+**repair()**——借壳=换好车)。

**红线:碰撞体只用双方盒(body+cabin),不用凸包/三角网格**(与 CCD+悬挂射线组合会 Rapier WASM panic)。

## 6.3 src/gameplay/PlayerManager.ts

常量:`ENTER_RANGE=3`、`EXIT_OFFSET=(2.0,0.3,0)`(车局部 +X 左门)、`EJECT_IMPACT=9`。

构造 `(character, controller, vehicles, traffic, cameraRig, input)`;字段 `onCarjack`、`onEjected`;getter `activeVehicle`、`isDriving`、`hint`、`ridingVehicle`(仅 spec.lean 车返回)。

- 驾驶输入:`throttle=W-S`、`steer=A-D`、`brake=isDown('Space')`,传 `activeVehicle.fixedUpdate`。
- 停车模拟:非驾驶且非 stashed 的自有车每步 `fixedUpdate(dt,{0,0,brake:true})`。
- 上车(E,距任意车 <3):自有车直接上;AI 车=抢车 → `traffic.swapWithPlayer(idx, oldX, oldZ, oldYaw, oldType, leaveShell=!wasStashed)`:主车 `teleportTo`+`setCarType` 换装,AI 车原地变旧车壳(首次借壳 wasStashed=true 不留壳),触发 `onCarjack`。lean 车 `setRiding(true)` 否则 `setActive(false)`;相机 `setExcludeCollider(chassisCollider)`。
- 下车(E):落点 = EXIT_OFFSET 经车四元数旋转+车位,`y=max(exitPos.y, vehPos.y+0.3)`(防进地基);恢复角色。
- 摩托甩人:`spec.fragile && impactDv>9` → `throwSpeed=5+impactDv*0.6`,先 exitVehicle,再 `controller.knock(sin(yaw)·ts, cos(yaw)·ts, 5.5)`(yaw=visualHeadingYaw),回调 onEjected。
- `forceExit()`(医院复活用);`getCameraTarget(out)`(驾驶=车位,步行=脚底);hint:驾驶「按 E 下车」/近车「按 E 上车」/空。
