## 2.4 src/core/Physics.ts

- 从 `@dimforge/rapier3d-compat` 默认导入 RAPIER,文件末 `export { RAPIER }`——**全项目统一从本模块取 RAPIER**,保证 init 时序。
- `interface Gravity {x,y,z}`;`DEFAULT_GRAVITY = {x:0, y:-9.81, z:0}`。
- `class Physics`:`readonly world`;私有构造;`static async create(gravity=DEFAULT_GRAVITY)` → `await RAPIER.init()` 后 new;`step(dt)` → `world.timestep=dt; world.step()`。
- 模块级零分配缓冲 `const VEL = {x:0,y:0,z:0}`(Rapier 内部拷贝数值,复用安全)。
- `setVel(body, x, y, z)`:写 VEL 后 `body.setLinvel(VEL, true)`。
- `radialBlastImpulse(body, dx, dz, d, radius)`(爆炸径向掀飞):
  `falloff = 1 - d/radius`;`inv = 1/max(d, 0.5)`;`mass = body.mass()`;
  冲量 = `(dx*inv*14*falloff*mass, (6 + 5*falloff)*mass, dz*inv*14*falloff*mass)` → `applyImpulse`。

## 2.5 src/core/Engine.ts

导入:THREE、EffectComposer、RenderPass、UnrealBloomPass、OutputPass(均 examples/jsm)。

常量:`FIXED_DT = 1/60`;`MAX_FRAME_DT = FIXED_DT*5`;`STAT_WINDOW = 60`;`ADAPT_THRESHOLD_MS = 22`;`MIN_PIXEL_RATIO = 0.75`。

接口:
```ts
export interface EngineHooks { fixedUpdate?: (dt:number)=>void; update?: (dt:number, alpha:number)=>void }
export interface EngineStats { avgMs:number; maxMs:number; pixelRatio:number }
```

`class Engine`,公开 `readonly renderer / scene / camera / stats`(stats 初值全 0 除 pixelRatio=1)。

构造(顺序精确):
1. `WebGLRenderer({antialias:true, powerPreference:'high-performance'})`
2. 像素比 `min(devicePixelRatio, 1.5)`,setPixelRatio+setSize
3. `shadowMap.enabled=true`,`type=PCFShadowMap`
4. `toneMapping=ACESFilmicToneMapping`,`toneMappingExposure=0.95`
5. 挂进 container;`new Scene()`
6. `PerspectiveCamera(70, w/h, 0.1, 1000)`
7. `WebGLRenderTarget(w,h,{samples:4, type:HalfFloatType})`(4×MSAA + HDR)
8. `EffectComposer(renderer, target)` + RenderPass + `UnrealBloomPass(Vector2(w,h), 0.06, 0.42, 1.35)`(strength/radius/threshold)+ OutputPass
9. `window.addEventListener('resize', onResize)`(resize 时更新 camera.aspect、renderer/composer 的 size,不动 pixelRatio)

方法:`setBloom(strength)`(bloomPass.strength=)、`setHooks(hooks)`、`start()`(`lastTime=performance.now()`,`renderer.setAnimationLoop(tick)`)、`stop()`。

tick(now) 伪代码:
```
rawMs = now - lastTime;  dt = min(rawMs/1000, MAX_FRAME_DT);  lastTime = now
统计:statAcc+=rawMs, statMax=max(...), 每 60 帧结算 avgMs/maxMs 并清零;
  若 avgMs > 22 且 pixelRatio > 0.75:pixelRatio -= 0.25(下限 0.75,只降不升),
  renderer 与 composer 都重设 pixelRatio 与 size
accumulator += dt
while accumulator >= FIXED_DT: hooks.fixedUpdate?.(FIXED_DT); accumulator -= FIXED_DT
alpha = accumulator / FIXED_DT
hooks.update?.(dt, alpha)
composer.render()
```

## 2.6 src/core/Input.ts

`interface MouseDelta {x,y}`。

沉浸模式函数(导出):
- `enterImmersive()`:非全屏则 `documentElement.requestFullscreen().catch(()=>{})`;`(navigator as any).keyboard?.lock?.()?.catch(()=>{})`(Keyboard Lock API,不支持静默)。必须在用户手势里调用。
- `exitImmersive()`:`document.exitPointerLock()`;在全屏则 `exitFullscreen().catch(()=>{})`。

`class Input`,构造 `(element: HTMLElement)`:
- `element.tabIndex = -1`、`style.outline='none'`、`focus({preventScroll:true})`——**焦点钉在 canvas 上屏蔽中文输入法**。
- 监听:window keydown/keyup/compositionstart/mousemove/mousedown/mouseup/wheel(passive)/focus;element click;document pointerlockchange/click/fullscreenchange。
- `compositionstart` → 对 target `blur()` 再 focus 回 canvas(打断组词)。
- keydown:`Escape` 特殊——非 repeat 时调 `exitImmersive()` 并 return(不进 down/pressed);locked 时 `preventDefault()`;非 repeat 加入 pressed;加入 down。
- element click:未锁定则 `enterImmersive()` + `element.requestPointerLock()`。
- pointerlockchange:`locked = (pointerLockElement === element)`;失锁时清空 down/pressed(防卡键);始终 focus 回 canvas。
- mousemove:仅 locked 时累积 movementX/Y。
- 鼠标键统一记作 `'Mouse'+button`(左键 `Mouse0`),与键盘共用 down/pressed。

公开:`isDown(code)`、`wasPressed(code)`(边沿)、`get pointerLocked`、`consumeMouseDelta()`(返回并清零)、`consumeWheel()`(返回并清零)、`endFrame()`(清 pressed,每帧末调)、`debugHold(code, on)`(测试注入)。
