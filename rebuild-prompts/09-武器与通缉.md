## 9.4 src/gameplay/Wanted.ts(最大文件,909 行,耐心完整实现)

### 星级与热度
`MAX_HEAT=3.99`;`stars=min(3,floor(heat))`;`COUNT_BY_STARS=[0,2,3,4]`(警车数);`CAR_POOL=4`、`COP_POOL=8`。

`reportCrime(kind,x,z)`(末尾统一 `heat=min(heat,3.99); unseen=0; seen=true`):
- gunshot:`heat=max(heat,1)`;距上次 >0.4s 再 +0.1
- pedhit:`max(heat,1)+0.5`;carjack:`max(heat,1)+0.4`
- explosion:`max(heat,2)+0.4` 并 blastCops(x,z)
- cophit(冷却0.3s):`max(heat,1)+0.6`;copkill:`max(heat,2)+0.7`

`frameUp()`:`heat=max(heat,2.2)`(剧情栽赃);`clearAll()`。
视线/衰减:`SIGHT_CAR=50`、`SIGHT_COP=35`、`SIGHT_INTERVAL=0.4`(降频)、`EVADE_GRACE=6`、`DECAY_RATE=0.22/s`(unseen>6 后衰减,heat<1 收兵清零)。
`evading = stars>0 && unseen>2`;`sirenLevel = stars==0?0 : clamp(1-nearestDist/90, 0.12, 1)`。

### 警车(池 4,kinematic,police 车型双盒)
常量:`RESPAWN_DIST=170`、`SPAWN_MIN=55`、`SPAWN_MAX=90`、`DIRECT_RANGE=26`、`CORRIDOR=6.5`、`STOP_DIST=6`、`SIEGE_DIST=14`、`SIEGE_BREAK=40`、`TURN_RATE=2.6`、`LANE_BLEND=6`;追击速度 `11+stars*1.5`。
- 巡航沿路网(advanceOnRoad+pickRandomDir:30% 转向);玩家在走廊内(距路中心线 <6.5)或距 <26 → 脱网直追(yaw 以 2.6 rad/s 转向目标)。
- 目标速度:默认 pursuit;玩家步行且 dist<6 → 0(不碾人);驾车 dist<5 → min(pursuit, playerSpeed+2);阻尼 `1-exp(-4dt)`。
- 撞步行玩家:dist<3.2 且 speed>5 且 ramCooldown≤0 → cooldown 1s,`controller.knock(dx·inv·7, dz·inv·7, 3.5)` + `onPlayerHit(16)`。
- 围捕:stars≥2 且 dist<14 且 playerSpeed≤8 且未派人 → 两侧(±1.7)下 2 名警察,mode='siege' 停车;dist>40 或玩家提速 >8 → 收警回车 chase。
- retreat(收兵):roadFollow 8m/s,dist>110 或 10s 收回。
- 生成:环 55~90,50% 纵路 50% 横路,西界夹紧(-224+16 / dir3 且 x<-160 改 dir1);speed=8。
- 警灯:`phase=(time*4)%1<0.5` 红蓝交替 emissive 3.2/0.15;红 0xff2020@(0.24,1.52,-0.25)、蓝 0x2266ff@(-0.24,…),Box(0.26,0.12,0.2),基础 0.3。

### 步行警察(池 8,Mage 皮肤,手枪模型同 Weapons)
常量:`COP_RUN=5.2`、`COP_SHOOT_RANGE=13`、`COP_DESPAWN=60`、`COP_DOWN_TIME=2.5`、`COP_MAX_HP=100`、`COP_KNOCK_DMG=45`、`COP_DEAD_TIME=4.5`、`KNOCK_SPEED=6`、`OCEAN_EDGE_X=-320`(不下海)、`TRACER_LIFE=0.06`、`CENTER_ABOVE_FEET=0.9`;胶囊 capsule(0.6,0.3) dynamic+lockRotations+damping(0.2/1.5)+CCD;血条 +2.05。
- dist>13 追(x<-320 且向西则停+Idle);≤13 站定 `1H_Ranged_Aiming` 射击。
- 开火:初始 `0.5+rand*0.5`,之后 `1.35-stars*0.15+rand*0.4`;命中率 `rand < 0.5+stars*0.08`;射前 `dist>3 && !LoS` 不开火;开火惊散 panicAt(22)。
- 命中:`onPlayerHit(11+stars*2)`;驾车对底盘冲量 `(nx*0.35,0.05,nz*0.35)*mass`,步行 `knock(nx*2.4, nz*2.4, 1.0)`。未命中曳光偏 `(±1.5,0~1.5,±1.5)`;命中偏 (0,0.3,0)。
- 被撞(水平速>6):hp-=45,down(dead?4.5:2.5),Death_A,报 copkill/cophit;活人 horizSpeed<1.2 爬起(Lie_StandUp,pause 0.9);y<-2.5 直接 despawn;距玩家 >60 收兵。
- `applyBulletDamage(body,dmg)`:命中→扣血,死→Death_A+copkill,活→cophit。
- `blastCops(x,z)`:radius 8,`radialBlastImpulse`,`hp-=90*(1-d/8)`。

### 视线检测
```
hasLineOfSight(eye, exclude):
  target = playerPos+(0,0.3,0);dist<2.5 → true
  castRay(dist-2, solid, 排除自身 collider+刚体)
  无命中 → true;命中→仅当驾车且命中自己车体才 true
anyUnitSees():任一 active 非 retreat 警车(d<50, 眼高1.2)或 active 非 down 警察(d<35, 眼高+0.5)
```
fixedUpdate 内 0.4s 降频调用;seen 时 unseen=0,否则 unseen+=dt。

### 公开接口
`fixedUpdate(dt, playerPos, driving, vehicle)`、`endStep()`、`update(dt,alpha)`(渲染插值+警灯闪)、`reportCrime`、`clearAll`、`frameUp`、`applyBulletDamage(body,dmg):boolean`、`forEachUnit(cb)`(小地图:警车/警察)、getter `stars/evading/sirenLevel`、回调 `onPlayerHit(dmg)`。

## 9.5 src/gameplay/Health.ts

常量:`MAX_HP=100`、`REGEN_DELAY=6`、`REGEN_RATE=5`、`HOSPITAL_FEE=100`、`DEATH_TIME=2.4`、`INVULN_TIME=3`;初始 `hp=100, money=800`。
- `damage(n)`:死亡/无敌/n≤0 免疫;扣血,sinceDamage=0,`flash=min(1, 0.45+n/40)`;hp≤0 → isDead、deathTimer=2.4、`money=max(0,money-100)`、黑幕显示。
- `update(dt)`:invuln/sinceDamage 计时;活着且 hp<100 且 sinceDamage>6 → +5/s;flash 衰减 1.8/s,红屏 opacity=`min(1,flash)*0.85`;死亡到点 → 复活(hp=100, invuln=3),回调 `onRespawn`。
- `addMoney(n)`(round)、`spend(n)`(不足返回 false)。
- 红屏 DOM:`fixed;inset:0;z-index:9;pointer-events:none;opacity:0;background:radial-gradient(ellipse at center, transparent 52%, rgba(255,28,28,.6) 100%)`。

## 9.6 main.ts 接线增量(逐条)

- `weapons.onCrime = (kind,x,z)`:`wanted.reportCrime(kind,x,z)`;explosion 时对每辆非 stashed 自有车 d<8 → `v.damage(70*(1-d/8))`(殉爆链)。
- `pedestrians.onHitByPlayerCar` → `wanted.reportCrime('pedhit')` + `audio.pedHit(true)`。
- `weapons.onHitBody = (body,dmg)` → `pedestrians.applyBulletDamage 未命中再 wanted.applyBulletDamage`。
- 每辆车 `v.onExploded` → `weapons.explodeAt(pos.x, pos.y+0.5, pos.z)`。
- `playerManager.onCarjack` → `wanted.reportCrime('carjack')` + `story.notifyCarjack()`(下阶段)。
- `wanted.onPlayerHit(dmg)`:驾驶 → `activeVehicle.damage(6)` + `health.damage(dmg*0.5)`;否则全额。
- `weapons.onPlayerBlast(dmg,dx,dz)`:`health.damage(dmg)`;非驾驶 `controller.knock(dx*9, dz*9, 4.5)`。
- `playerManager.onEjected` → `health.damage(25)`。
- `controller.onHardLanding(v)` → `health.damage(min(50,(v-12)*4))` + `audio.land(true)`。
- `health.onRespawn` → `playerManager.forceExit()` + `character.teleport(spawnPoint)` + `controller.reset()` + `wanted.clearAll()`。
- 驾车撞击(fixedUpdate):`iv>4 → audio.crash(min(1,iv/22))`;`iv>10 → health.damage(min(45,(iv-10)*2.5))`。
