## 10.3 src/gameplay/Shops.ts

坐标:武器店 `(53.5, 10.5)`;喷漆店 `(-42.5, 74.5)`。范围:`GUN_RANGE=4.5`(步行)、`SPRAY_RANGE=6`(开车)。价格:手枪弹 100/机枪弹 150/手雷 120/喷漆 200/修车 150。
光柱(常亮):武器店 0x54a8ff r1 h10 opacity0.16;喷漆店 0xff9a3d 同。

武器店面板(dGun<4.5 且步行,accent #54a8ff):
```
【武器店】现金 ${money}

K 机枪弹 +120　$150(现 {n})

```
J/K/L → `buyAmmo(kind, price, count)`:spend 成功 → addAmmo+blip+toast `✓ 已购买(-$价格)`;否则 `现金不足`。

喷漆店面板(dSpray<6 且驾驶,accent #ff9a3d):
```
【喷漆店】现金 ${money}

K 修车　$150(车况 {ceil(condition)}%{wrecked?'·报废':''})
```
J:无通缉 → `现在没人在追你`;spend(200) → `wanted.clearAll()`+blip+`✓ 换了新涂装,警察认不出这辆车了`。K:车况满 → `这车好得很,不用修`;spend(150) → `vehicle.repair()`+blip+`✓ 修好了,跟新的一样`。
msg 停留 2.5s。面板 DOM:`fixed;right:12px;bottom:12px;z-index:11;max-width:340px;background:rgba(8,10,14,.75);border-left:3px solid <accent>;border-radius:6px;padding:8px 14px;color:#f2f2f2;font:13px/1.7 system-ui;white-space:pre-line`。`forEachShop(cb)`:(53.5,10.5,'#54a8ff') 与 (-42.5,74.5,'#ff9a3d')。

## 10.4 src/gameplay/TaxiJobs.ts

常量:`PICKUP_MIN=60, PICKUP_MAX=140`、`DEST_MIN=120, DEST_MAX=260`、`ARRIVE=5.5`、`STOP_SPEED=2`(km/h)、`NEXT_FARE_DELAY=2.5`;初始 cooldown=1;乘客=spawn('Rogue');绿柱 0x51ff7e r1.2 h16 opacity0.25 pulse{0.18,0.08}。
计价:`fareBase = round(35 + 上车瞬间玩家到目的地距离 * 0.4)`。

状态机(仅当驾驶 taxi):
- none:cooldown 到 → pickCorner(60~140) 放接客点+乘客可见,toast `新乘客在招手——去接客(停稳车)`。
- pickup:乘客面向车;d<5.5 且 |kmh|<2 → 乘客隐藏,pickCorner(120~260) 放目的地,算 fareBase,toast `乘客上车:送到目的地(车费 $N)`。
- ride:d<5.5 且停稳 → `addMoney(fareBase)`+blip+toast `✓ 送达!+$N`,cooldown=2.5。
非 taxi 时有单 → toast `乘客跑单了——回到出租车上重新接单` 并取消。
`pickCorner(from,min,max,out)`:随机角度与距离;`bx=max(round((x+cosθ·dist)/32)*32, -224)`;`bz=round(…)*32`;sx/sz=±1 随机;out=(bx+sx*10.5, 0, bz+sz*10.5)。
toast DOM:`fixed;left:50%;bottom:20%;translateX(-50%);background:rgba(8,14,8,.72);border-left:3px solid #51ff7e;圆角6;padding 6px 14px;color:#eaffea;font 14px/1.6`,停留 3.2s。`targetInfo(out)`:pickup→`乘客`,ride→`目的地`。

## 10.5 src/gameplay/Story.ts(台词逐字,不得改动)

坐标:老周 `(85.5, -53.5)`;码头场子 `(-172, 108)`;海滩销赃点 `(-262, 16)`;`MOTO_UNSTASH_DIST=110`;`ARRIVE_DIST=6`。
状态:`'idle'|'steal'|'evade'|'meet'|'chase'|'reclaim'|'moto'|'done'`。
老周 NPC:spawn('Barbarian')@(85.5,0.04,-53.5),rotation.y=-π/4,播 Idle。
金柱 Beacon:0xffd34d r1.4 h22 opacity0.3 pulse{0.22,0.1}。
字幕框 DOM:`fixed;left:50%;bottom:11%;translateX(-50%);z-index:11;max-width:620px;min-width:260px;background:rgba(8,10,14,.72);border-left:3px solid #ffd34d;圆角6;padding 10px 16px;color:#f2f2f2;font:14px/1.65 system-ui`。
`say(...)`:每行 `dur=min(5, 2.2+len*0.07)` 排队;`objective(text)`:队列空时显示 `<span style="color:#ffd34d">任务</span>　{text}`(全角空格)。

构造 `(scene, personLib, vehicle, motorcycle, traffic, wanted)`;`notifyCarjack()`;`start()`;`update(dt, playerPos, driving, drivingSedan, drivingMoto, stars)`;`targetInfo(out)`。

**start()(idle→steal)三行**:
1. `凌晨四点,你被楼下的动静吵醒。`
2. `停好的爱车和摩托,一夜之间被"码头帮"搬空了。`
3. `这座城市不讲道理——想拿回东西,只能自己动手。`

**steal**:光柱=最近 AI 车(label `路车`);objective `搞辆代步车:靠近路上的车按 E 抢走(小心引来警察)`。触发 carjacked||driving:stars>0 → 说 `✓ 到手了。警笛声近了——先甩掉他们再说。` 转 evade;否则说 `✓ 到手了。听说修车行的老周消息灵通。` 转 meet。

**evade**:无光柱;objective `甩掉通缉:拐进小巷、绕到楼后,脱离警察视线`;stars==0 → `✓ 风头过了。修车行的老周消息灵通,去问问你的车。` 转 meet。

**meet**:光柱 `老周`;objective `去修车行找老周打听消息`;距 <6 触发三行:
1. `老周:哟,新面孔。车被码头帮收走了?`
2. `老周:他们的跑腿每天开辆面包车在城里送货。`
3. `老周:把车逼停,他什么都会说。`
然后 `courierIdx = traffic.markCourier(playerPos)` 转 chase。

**chase**:光柱 `跑腿` 跟随 courierState;objective `逼停帮派跑腿的面包车(堵住去路或撞停它)`;触发 `(dist<7 && speed<0.8) || (carjacked && 主车型=='delivery')`:
1. `跑腿:别动手!车…车在西边码头的场子里!`
2. `跑腿:摩托拉去海滩销赃了,现在去还来得及!`
转 reclaim。

**reclaim**:光柱 `场子`@(-172,108)。未放车:objective = dist<25 且驾驶 ? `在场子附近下车查看` : `去西边码头帮的场子夺回爱车`;dist<20 且步行 → sedan `setStashed(false)`+`teleportTo(-172,108,π/2)`+`setCarType('sedan-sports')`,说 `你把偷来的车丢在一边——爱车就停在场子中央,一点没刮花。`。已放车:objective `按 E 开走你的爱车`;drivingSedan 且车型 sedan-sports → `wanted.frameUp()`(2.2 热度栽赃),说 `✓ 帮派眼线立刻报了警,栽赃你"偷车"——甩掉警察,去海滩!`,转 moto。

**moto**:光柱 `摩托`@(-262,16);objective `去海滩销赃点骑回你的摩托`;dist<110 时 moto `setStashed(false)`+`teleportTo(-262,16,π/2)`;drivingMoto 触发:
1. `✓ 都拿回来了。`
2. `海风里,这座城市终于还清了欠你的东西。——自由行动,想去哪就去哪。`
转 done。done 且队列空 → 清字幕框。
