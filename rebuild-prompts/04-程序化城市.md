## 4.1 City.ts —— 纯数据城市生成器(不碰 three/rapier)

### 网格常量
`BLOCK_SIZE=24`(街区边长)、`ROAD_WIDTH=8`、`PITCH=32`(街区中心间距,导出)、`PLOT_HEIGHT=0.04`(地皮薄贴面,导出)、`CHUNK_BLOCKS=3`(每 chunk 3×3 街区)、`CHUNK_SIZE=96`(导出)、`SAND=0xe3d2a4`、`SEABED=0xc8b184`。

### 分区
`ChunkZone = 'city'|'beach'|'ocean'`;`COAST_CX=-3`(该列 chunk 是沙滩);`OCEAN_FLOOR_Y=-1.8`;`CITY_MIN_BLOCK_X=(COAST_CX+1)*CHUNK_SIZE-PITCH=-224`(导出)。`chunkZone(cx)`:cx>-3→city,==-3→beach,<-3→ocean(x 向西递减:城市→沙滩1列→海)。

### 路网寻路约定(导出,Traffic/Wanted 共用)
`HALF_ROAD=16`(道路中心线 ≡16 mod 32);方向 0=+z,1=+x,2=-z,3=-x;`DIR_X=[0,1,0,-1]`、`DIR_Z=[1,0,-1,0]`;右车道横偏 `LANE_X=[-2,0,2,0]`、`LANE_Z=[0,2,0,-2]`;`snapToRoad(v)=round((v-16)/32)*32+16`。

### 人行道/宅地
`SIDEWALK=3`;`SIDEWALK_LINE=10.5`(导出);`LOT=9`;`CITY_SEED=20260717`;`BUILDING_COLORS=[0xd9c9b4,0xc9a184,0xbfb4a8,0x9caebc,0x8d7f72]`。

### 数据结构(导出接口)
```
BoxInstance { x,z,w,h,d,base,color, solid, windows?, facade?, kind?:'glow'|'pool'|'signal', rotX?, hidden? }
DoorSpec { hx,hz, swing }          // 门板沿 z 长 1.2m,swing 内开方向符号
StairZone { x0,x1,z0,z1, zf,zt, base,top }  // 沿 z 从 zf(高 base) 线性升到 zt(高 top)
PropSpec { type, x,z, rotY, y? }
ParkedCarSpec { type:CarType, x,z, rotY }
ChunkData { boxes, doors, stairs, props, cars }
RoadRunner { dir, currPos:{x,z} }
```
体块 (x,z) 为中心水平坐标,base 为底面高度,中心 y=base+h/2。

### 确定性随机
- `mulberry32(seed)` 标准实现:`a=(a+0x6d2b79f5)>>>0; t=a; t=imul(t^(t>>>15), t|1); t^=t+imul(t^(t>>>7), t|61); return ((t^(t>>>14))>>>0)/4294967296`。
- `chunkSeed(cx,cz)=(imul(cx,73856093)^imul(cz,19349663)^CITY_SEED)>>>0`。
- **rand 消费顺序必须与本规格完全一致**(洗牌→special→停车→盖楼;每街区先楼、后路灯、再红绿灯),否则同种子布局不同。

### generateChunk(cx,cz) 主流程
```
rand = mulberry32(chunkSeed(cx,cz));  zone = chunkZone(cx);  GROUND_THICK = 4
// 地基:
if zone=='ocean' && cx==-4(近岸):
  东侧 32m 浅滩 box{x:cx*96+32, z:cz*96, w:32,h:4,d:96, base:-4.3, color:SEABED, solid}
  深水段       box{x:cx*96-16, z:cz*96, w:64,h:4,d:96, base:-5.6, color:SEABED, solid}
else:
  groundTop = ocean?-1.8:0
  box{x:cx*96,z:cz*96,w:96,h:4,d:96, base:groundTop-4, color:beach?SAND:SEABED,
      solid, hidden:(zone=='city')}   // 城市地基只碰撞不渲染(路面贴图接管)
city → 3×3 街区循环;beach → 棕榈+礁石;ocean 仅地基(水面由 ChunkManager 加)
```
城市街区循环:`shopBlock=floor(rand()*9)`;`towerBlock=(shopBlock+1+floor(rand()*8))%9`;bi/bj 双循环,`x=cx*96+(bi-1)*32`、`z=cz*96+(bj-1)*32`,依次调 generateBlockBuildings(special=shop/tower/null)、generateStreetLamps、generateTrafficSignal。

沙滩:棕榈 `4+floor(rand()*3)` 棵,type 从 `[tree_palm, tree_palmBend, tree_palmDetailedTall, tree_palmDetailedShort]` 取,`x/z = cx*96+(rand-0.5)*(96-10)`,rotY 随机;礁石 `2+floor(rand()*3)` 块,`[rock_largeA, rock_largeC, rock_smallA, rock_smallE]`,范围 `(96-8)`。

### generateBlockBuildings(单街区核心)
```
lots=[[-0.5,-0.5],[-0.5,0.5],[0.5,-0.5],[0.5,0.5]](单位 LOT=9);Fisher–Yates 洗牌(i 从 3 到 1)
special 时 lots.pop() 建 shop/tower(s = li>0?1:-1)
count = min(2+floor(rand()*3), lots.length)
// 未盖楼宅地→停车位:
for [li,lj] in lots.slice(count):
  rand()<0.3 → 空地跳过
  n=1+floor(rand()*2) 辆;alongZ=rand()<0.5
  off=(k-(n-1)/2)*2.7;x/z 沿排布轴用 off、另一轴 (rand-0.5)*1.5
  rotY = (alongZ?0:π/2) + (rand<0.5?π:0) + (rand-0.5)*0.1
  type 从 PARKED_TYPES=[sedan,suv,taxi,hatchback-sports,suv-luxury,delivery] 取
// 盖楼宅地:
for [li,lj] in lots.slice(0,count):
  roll=rand()
  roll>=0.55 → Kenney GLB 建筑:rotY=(li>0?π/2:-π/2)(门面朝外);
    roll<0.72 → 'building-skyscraper-'+[a-e 随机];否则 'building-'+[a-n 随机]
  否则程序化幕墙楼(55%):
    w=9*(0.55+rand*0.35); d 同;x=cx0+(rand-0.5)*(9-w); z 同
    h = rand<0.45 ? 13+rand*14 : 30+rand*28
    facade=floor(rand*4);color 从 BUILDING_COLORS 取
    box{x,z,w,h,d, base:0.04, color, solid, windows:true, facade}
    裙楼(h>15 且 rand<0.6):box{w+0.9, d+0.9, h:3.2, base:0.04, color:0x55504a, solid:false}
    屋顶设备 1~3 个:box{x±rand*w*0.25, w:0.6+rand*0.9, h:0.5+rand*0.9, d:0.6+rand*0.9,
      base:0.04+h, color:rand<0.5?0x8d8d8d:0x6e6a63, solid:false}
    塔尖(h>26 且 rand<0.5):box{w*0.6, d*0.6, h:5+rand*6, base:0.04+h, color, solid, windows, facade}
```

### advanceOnRoad(car, speed, dt, pickDir)(导出)
```
prevAlong = dir偶?z:x;前进;along=新值;step=along-prevAlong
line = snapToRoad(prevAlong + step*0.5 + sign(step)*0.01)
crossed = prevAlong 与 along 跨过 line
crossed → newDir=pickDir(dir,x,z);若变向:行进轴钉在 line+LANE、横轴 snapToRoad+LANE
西界调头:x < -240 且 DIR_X[dir]<0 → dir=1, x=snapToRoad(x)+LANE_X[1]
return atan2(DIR_X[dir], DIR_Z[dir])
```

## 4.2 ChunkManager.ts —— 流式加载

### 常量与共享资源

- `setCityNight(n)`:emission 幕墙 `emissiveIntensity=1.05*n`;GLOW 色 `setScalar(0.5+1.0*n)`;POOL opacity `0.38*n`。
- `setCityWetness(w)`:路面材质 `roughness=0.95-0.72*w`;`color.setScalar(1-0.32*w)`。
- `updateCitySignals(time, intensity=1)`:周期 `t=time%10.2`;绿 0~4.5(0x33dd55)→黄 4.5~5.7(0xffcc33)→红 5.7~10.2(0xff3333);`setHex().multiplyScalar(intensity)`(夜里 >1 进 HDR 参与 Bloom)。

### Chunk 类
构造 `(scene, physics, cx, cz, boxes, props, propLib, cars, carLib)`:
1. 停靠车:fixed 刚体 @(x, 0.04, z)+rotY 四元数;`carLib.colliderBoxes` 的 body/cabin 各 cuboid(hx,hy,hz).setTranslation(0,cy,cz);视觉用 `bakedParts` 按材质分组、几何 clone+`makeRotationY(rotY).setPosition(x,0.04,z)`、mergeGeometries 成 Mesh(cast+receiveShadow)。
2. GLB 道具:按 matKey 分组,几何 clone+rotY+setPosition(x, y??0.04, z),merge 成 Mesh。
3. city 区:路面 Mesh @(cx*96, 0.004, cz*96),receiveShadow。
4. ocean 区:water Mesh(浅/深按 nearShore=cx==-4),rotX -π/2,@(cx*96, -0.06, cz*96);nearShore 加两道浪花 @(cx*96+46, -0.01) 与 (cx*96+39, 0.0)。
5. 体块 InstancedMesh 分类:plain(非 windows/kind/hidden)→BOX_MATERIAL;幕墙按 facade%4 分组→FACADES[f].materials;glow→GLOW;pool→POOL_GEO+POOL(不投不接阴影);signal→SIGNAL。矩阵 compose(pos=(x,base+h/2,z), identity, scale=(w,h,d))+setColorAt(color)。
6. `pending = boxes.filter(solid).reverse()`(**倒序,地基最先建,防高速驶入掉落**)。

方法:`buildColliders(physics, budget)` 每次 pop 建 cuboid(w/2,h/2,d/2)@(x,base+h/2,z)(rotX 有则设 X 旋转);`disposeSome(scene,physics,budget)` 先清 pending、逐个 removeCollider,空了再移除刚体/网格(几何 dispose,共享材质不释放)。

### ChunkManager 类
- 构造 `(scene, physics, initialPos, propLib, carLib)`:建 DoorSystem(公开 `readonly doors`),然后 `update(initialPos, Infinity)`(出生全就位)。
- `update(playerPos, budget=20)`:pcx/pcz=round(pos/96);超 UNLOAD_RADIUS(chebyshev)→标记 dead 入 disposeQueue、移除 doors/stairZones;环形加载 r=0..2,**预算有限时每帧最多新建 1 个 chunk**(generateChunk→decorateBuildings→injectPropColliders→new Chunk→登记 doors/stairs);花预算:先 buildQueue(建)后 disposeQueue(拆)。
- `stairHeightAt(x,z,feetY)`:查所在 chunk 的 StairZone,`t=clamp((z-zf)/(zt-zf),0,1)`,`h=base+t*(top-base)`,取 `h<=feetY+0.7` 的最高层,否则 null。
- `animateWater(time)`:waterChunks==0 直接 return;对 WATER_GEO 每顶点 `z = 0.22*sin(a)+0.12*sin(b)+0.1*sin(c)`,其中 `a=(x/96)*2π*3-time*1.4`、`b=((x+y)/96)*2π*2-time`、`c=(y/96)*2π*5+time*2.1`;解析法线(dhdx/dhdy);浪花 opacity `0.28+0.24*(0.5+0.5*sin(t*1.6))` 与 `0.1+0.2*(0.5+0.5*sin(t*1.6-1.8))`。

### decorateBuildings(确定性楼体装饰)
`SIGN_COLORS=[0xff5548,0x4db4ff,0xffd24d,0xff7fc2,0x5dffb0,0xffffff]`;只遍历原始 props(kit=='buildings' 且非 detail-);坐标哈希种子 `(imul(round(x*7),73856093)^imul(round(z*7),19349663))>>>0`+LCG(`seed*1664525+1013904223`);fx/fz=临街面外推 depth/2+0.12;非塔且 rnd<0.6 加雨棚/挑檐(wide 判定 width>6.5 且 rnd<0.5;kind awning/overhang 各半;y=2.59);屋顶设备 1~2 个(w/h/d 0.7+rnd*0.8 / 0.5+rnd*0.8 / 0.7+rnd*0.8,色 0x9a9a98/0x77726b);女儿墙(isTower||rnd<0.5,w*0.98,h 0.5,base roof-0.05,0x8a8378);发光店招(非塔且 rnd<0.45,沿临街面 1.5×0.22×2.2,base=0.04+min(size.y*0.4,4.2),色随机,kind:'glow')。

### injectPropColliders(GLB 道具隐形碰撞)
detail- 不碰撞;props(路灯)→细杆 {0.24,4.6,0.24};tree_→树干 {0.35, size.y, 0.35};其余建筑→整体 AABB(|sin rotY|>0.5 时对调宽深)。全部 hidden:true, solid:true。

## 4.5 Doors.ts —— 商店门
