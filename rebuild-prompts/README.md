# rebuild-prompts — 用 vibe coding 1:1 复刻本游戏的提示词包

这个目录是一套**可直接投喂给 AI 编程助手**(Claude Code / Cursor 等)的分阶段提示词,
目标是让任何人不看本仓库源码,仅靠这套提示词,从零复刻出与
`D:\AI\claude\game\gta5` 行为、数值、界面完全一致的开放世界游戏。

## 先说清楚"1:1"的边界

- **逐字节一致**(变量名、注释、文件哈希都相同)只有一个办法:直接拷贝本仓库源码。任何提示词驱动的重写都做不到。
- 本提示词包做到的是**数值级 / 行为级 / 界面级 1:1**:所有玩法数值(伤害、价格、速度、
  通缉热度、剧情台词逐字)、目录结构、类与回调接口、UI 文本与样式、素材文件都与原版完全一致。
  玩家坐下来玩,两个版本无法区分;调参位置也一一对应。
- 程序化城市使用与原版相同的**固定随机种子算法**,城市布局也一致。

## 使用方法

1. 新建空目录,启动你的 AI 编程助手。
2. **第一条消息**:把 `00-开发总纲.md` 全文发给 AI,并说明"这是整个项目的总纲,后续每个阶段都必须遵守"。
3. **依次**把 `01` ~ `10` 每个阶段文件全文发给 AI,一次一个阶段。每个阶段末尾有
   **验收清单**——让 AI 自查通过、你在浏览器里逐条确认后,再进入下一阶段。
4. 阶段之间建议 `git commit` 一次,出问题可整轮回退。
5. 全部完成后跑 `99-最终验收.md` 做整体验收。

> 素材(模型/音效/贴图)是外部 CC0/CC-BY 资源,AI 无法凭空生成——`01-资产准备.md`
> 给出了每个文件的精确来源与重命名映射,这一步是人工/脚本下载,不是 vibe coding。
> 图省事也可以直接把本仓库的 `public/` 目录整个拷贝到新项目(许可允许)。
