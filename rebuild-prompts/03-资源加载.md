# 03 · 资源加载库与骨骼动画共用

> 本阶段实现:`src/core/Loader.ts`、`src/core/CharacterAnim.ts`。依赖 01 阶段的 public/ 素材。

## 3.1 src/core/Loader.ts

导入:THREE、GLTFLoader、SkeletonUtils、mergeGeometries(BufferGeometryUtils)、OBJLoader、MTLLoader。

### 车辆库 CarLibrary

- `CarType = 'sedan'|'sedan-sports'|'suv'|'suv-luxury'|'taxi'|'hatchback-sports'|'police'|'delivery'`;`ALL_CAR_TYPES` 全 8 种。
- 导出 `TRAFFIC_TYPES = ['sedan','suv','taxi','hatchback-sports','suv-luxury','delivery']`(6 种,不含 sedan-sports/police,便于识别玩家车与警车)。
- `TARGET_LENGTH = 4.4`(目标车长,沿 Z 缩放对齐)。路径 `/models/cars/<type>.glb`。
- 接口:`CarPart{geometry, material}`;`CarBox{hx,hy,hz,cy,cz}`(半尺寸+中心偏移,车根坐标系:原点车底中心,+Z 车头);`CarBoxes{body, cabin|null}`。

`static async load()`:并行加载 8 种。每种:Box3 量尺寸 → `s = 4.4/size.z` → `scale.setScalar(s)` → position 设为 `(-(min.x+max.x)/2*s, -min.y*s, -(min.z+max.z)/2*s)`(居中贴地)→ traverse Mesh:castShadow=true,材质贴图 colorSpace=SRGB → 包一层 Group 存模板。

方法:
- `clone(type, hideWheels)`:模板 `clone(true)`(共享几何材质);hideWheels 时把 `name.startsWith('wheel')` 的设 invisible;未加载抛错「未加载的车型: 」。
- `bakedParts(type)`(懒缓存,停靠车合并渲染用):updateMatrixWorld 后按材质分组,每 Mesh 几何 clone 并 applyMatrix4(matrixWorld) 烘焙到车根系;同材质多几何 mergeGeometries(合并后 dispose 中间几何)。返回共享模板——调用方 clone 几何用,**不得释放材质**。
- `colliderBoxes(type)`(缓存,实测双盒碰撞规格):扫描全部顶点求整车 AABB;`cabinLine = maxY*0.55`;body 盒 `{hx:(maxX-minX)/2, hy:cabinLine/2, hz:(maxZ-minZ)/2, cy:cabinLine/2, cz:(maxZ+minZ)/2}`;座舱盒仅统计 y≥cabinLine 的顶点,顶点数 ≥3 才生成否则 null。
  **红线:只用方盒。凸包+动态车身+CCD+悬挂射线的组合会触发 Rapier WASM panic。**

### 建筑/道具库 PropLibrary

类型清单:
- `BUILDING_PROP_TYPES`:building-a … building-n(14 个);`SKYSCRAPER_PROP_TYPES`:building-skyscraper-a…e(5 个);`LAMP_PROP_TYPES`:['light-curved'];`DETAIL_PROP_TYPES`:detail-awning / detail-awning-wide / detail-overhang / detail-overhang-wide / detail-parasol-a / detail-parasol-b;`NATURE_PROP_TYPES`:tree_palm / tree_palmBend / tree_palmDetailedTall / tree_palmDetailedShort / rock_largeA / rock_largeC / rock_smallA / rock_smallE。
- 路径:buildings/skyscraper/detail → `/models/buildings/`;lamp → `/models/props/`;nature → `/models/nature/`。
- 常量:`LOT_FIT = 8.6`(占地上限,9m 宅地内);`SKYSCRAPER_H = 30`;`LAMP_H = 5`。
- `PropKit = 'buildings'|'props'|'nature'`;`PropPart{geometry, matKey}`;`PropDef{parts, size:Vector3, kit}`。

缩放函数 `propScale(type, kit, raw)`:
```
nature:  tree_palm* → (含'Short'?3.6:5.6)/raw.y;rock_large*→1.7/raw.y 否则 0.7/raw.y
props:   5/raw.y
detail-parasol* → 2.2/raw.y
detail-* → (含'wide'?4.6:2.6)/raw.x
含'skyscraper' → min(8.6/max(raw.x,raw.z), 30/raw.y)
其余建筑 → 8.6/max(raw.x,raw.z)
```

`static async load()`:并行;每模型量 AABB → 算 s 与居中偏移(ox=-(min.x+max.x)/2, oy=-min.y, oz=-(min.z+max.z)/2)→ traverse Mesh:材质 key=`${kit}:${mat.name||'default'}` 全库共享(首见时贴图设 SRGB 存入 materials);几何 clone → applyMatrix4(matrixWorld) → translate(ox,oy,oz) → scale(s,s,s),按 key 分组 mergeGeometries 成 parts。`def.size = raw.multiplyScalar(s)`。
全部加载后:`materials.get('buildings:colormap')` 若是 MeshStandardMaterial 则 `color.setHex(0xf5e0c4)`(建筑整体暖砂岩色调)。

方法:`def(type)`(不存在抛「未加载的道具: 」)、`material(matKey)`。

### 摩托 loadMotoModel()

MTLLoader+OBJLoader,path `/models/moto/`,bike.mtl+bike.obj;Mesh castShadow,Phong 材质贴图 SRGB;若 size.x>size.z 先 rotateY(π/2) 使长轴沿 Z;`s = 2.2/size.z`(车长 2.2m);居中贴地;包 Group 返回。

### 坦克 loadTankModel()

- `TANK_HULL_CENTER_Z = -0.675`(车体中心 Z,补偿炮管悬伸)。
- 并行加载 `/models/tank/tank.glb` 与 4 张贴图(Body_d/Body_n/Details_d/Details_n.jpg);贴图 `flipY=false`、anisotropy=4;漫反射两张 SRGB,法线保持线性。
- `bodyMat = MeshStandardMaterial{map:Body_d, normalMap:Body_n, roughness:0.82, metalness:0.18}`;`detailsMat = {map:Details_d, normalMap:Details_n, roughness:0.9, metalness:0.25}`。
- traverse Mesh:castShadow;`name.startsWith('Body')` 用 bodyMat 否则 detailsMat。
- **不缩放**(模型即米制);position `(-(min.x+max.x)/2, -min.y, -TANK_HULL_CENTER_Z)`;包 Group。

### 人物库 PersonLibrary

- `PersonType = 'Knight'|'Barbarian'|'Mage'|'Rogue'|'Rogue_Hooded'`;`ALL_PERSON_TYPES` 全 5 种;`PERSON_HEIGHT = 1.8`;路径 `/models/characters/<type>.glb`。
- `PersonInstance { root:Group, mixer:AnimationMixer, actions:Map<string,AnimationAction>, handSlotR:Object3D|null }`。

load:每模型 traverse Mesh:castShadow=true;**parent.name 以 'handslot' 开头的 Mesh 设 visible=false**(隐藏自带武器盾牌);`s = 1.8/(max.y-min.y)`;`position.y = -min.y*s`;`rotation.y = π`(模型面朝+Z → 项目约定面朝-Z);存 {scene, clips:gltf.animations}。

`spawn(type)`:`SkeletonUtils.clone(template.scene)`(骨骼深拷贝,几何材质共享);new AnimationMixer;每 clip → `actions.set(clip.name, mixer.clipAction(clip))`;traverse 找 `name === 'handslot.r' || 'handslotr'` 存 handSlotR。

## 3.2 src/core/CharacterAnim.ts

```ts
export interface ClipHolder { person: PersonInstance; currentClip: string; currentAction: AnimationAction|null }
export function playClip(holder, name, once=false, timeScale=1, fade=0.2): void
```
playClip 行为:actions 无此剪辑直接 return;`currentClip===name && !once` 时只更新 timeScale;否则 reset → `setLoop(once?LoopOnce:LoopRepeat, Infinity)` → `clampWhenFinished=once` → timeScale → 若有旧 action 且不同则 `crossFadeFrom(old, fade, false)` → play,更新 holder。

`placeSkinnedRoot(root, prevPos, currPos, prevQuat, currQuat, prevYaw, yaw, alpha, centerAboveFeet)`(模块级复用临时 Vector3/Quaternion,零分配):
```
POSE_V = lerp(prevPos, currPos, alpha)
POSE_Q = slerp(prevQuat, currQuat, alpha)
y = prevYaw + wrapAngle(yaw - prevYaw) * alpha      // yaw 最短弧插值
POSE_Q ×= AxisAngle(Y轴, y)
OFFSET = (0, -centerAboveFeet, 0) 经 POSE_Q 旋转     // 胶囊中心 → 脚底
root.position = POSE_V + OFFSET;  root.quaternion = POSE_Q
```
