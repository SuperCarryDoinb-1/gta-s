# 08 · 音频系统(采样 + 程序合成混合)

> 本阶段实现:`src/core/Audio.ts`(class GameAudio)。采样来自 `public/sounds/`,未加载完成前对应音效静默跳过;`start()` 必须在用户手势里调用。

## 常量

- 和弦进行 `CHORDS`(Am→F→C→G,每和弦 4 音 Hz):`[110.0,220.0,261.63,329.63]`、`[87.31,174.61,220.0,261.63]`、`[65.41,130.81,164.81,196.0]`、`[98.0,196.0,246.94,293.66]`;`CHORD_SECONDS=4`;`MUSIC_GAIN=0.15`。
- `ENGINE_GAIN=0.34`、`WIND_GAIN=0.18`。
- 采样变体 `VARIANTS={step:5, punch:5, crash:5, thud:3}`(文件 `/sounds/<键><i>.ogg`,i 从 0);`SINGLES=['horn','door_open','door_close','engine_start']`(`.ogg`);引擎循环 `/sounds/engine_loop.wav`。
- master 增益 0.9;`strideAcc` 初始 1.2;crash 冷却 0.12s。

## start() 建图(顺序)

1. `new AudioContext()`;master gain 0.9 → destination。
2. 引擎链:engineGain(0) ← engineFilter(lowpass 1000) ← engineSub(sine 32Hz, start);采样 engineSrc 加载后挂到 engineFilter(loop,playbackRate 0.5)。
3. 风噪:2s 白噪声 buffer(存 noiseBuf,全系统复用)→ lowpass 300 → windGain(0) → master,循环播放。
4. 雨声:noiseBuf → bandpass 2400 Q0.35 → rainGain(0) → master,`start(0,1)` 错开相位。
5. 警笛:triangle 720Hz;LFO sine 0.75Hz → gain 170 → siren.frequency(扫频 wail);sirenGain(0)。
6. 胎鸣:noiseBuf → bandpass 1500 Q3.5 → screechGain(0),`start(0,0.5)`。
7. `nextChordTime = currentTime+0.3`;异步 loadSamples(fetch+decodeAudioData,异常静默降级)。

## 接口与合成链路(参数精确)

- `playBuf(key, gain, rate=1, jitter=0)`(私有):随机变体,`playbackRate = rate*(1+(rand-0.5)*jitter)`,经独立 gain → master。
- `update(speedKmh, driving, throttle=0)` 每帧:
  - 音乐调度:提前 0.5s `scheduleChord`+`scheduleDrums`,chordIndex 循环,nextChordTime+=4。
  - `speed01=min(|speedKmh|/110, 1)`(NaN 归 0);
    rpm=`0.5+speed01^0.9*1.5+throttle*0.12`(setTarget τ0.09);sub 频率 `30+speed01*90+throttle*8`(τ0.09);filter `700+speed01*2600+throttle*400`(τ0.15);engineGain=driving?`0.34*(0.4+0.4*speed01+0.2*throttle)`:0(τ0.15);风 filter `300+speed01*900`、gain `speed01²*0.18`(τ0.2)。
- `setMovement(state, speed, dt)`:非 walk/run → strideAcc=1.2;否则 strideAcc+=speed*dt,步长 run 2.6/walk 1.7,触发 `playBuf('step', run?0.34:0.18, run?1.06:1, 0.16)`。
- `jump()`:playBuf('step',0.22,0.82,0.1) + 短风声(noiseBuf→bandpass 420→950Hz 0.18s,Q1.2;gain 0.06→0.001 0.22s;随机 offset,stop t+0.25)。
- `land(hard)`:playBuf('thud', hard?0.55:0.2, hard?0.85:1.05, 0.12)。
- `pedHit(runOver)`:playBuf('punch',0.5,1,0.18);runOver 加 playBuf('thud',0.6,0.9,0.1)。
- `crash(intensity)`:冷却 0.12s;k=min(i,1);playBuf('crash', 0.22+0.5k, 1.05-0.3k, 0.15);k>0.55 加 thud(0.5,0.8,0.1)。
- `setHorn(on)`:on→horn buffer 循环,gain 0→0.5 线性 0.02s;off→setTarget 0 τ0.03,stop +0.15。
- `door(open)`:playBuf(door_open/close, 0.45, 1, 0.06)。`engineStart()`:playBuf(0.4,1,0.04)。
- `setRain(w)`:rainGain→0.04w τ0.4。`setSiren(level)`:→min(level,1)*0.055 τ0.3。`setScreech(level)`:→min(level,1)*0.12 τ0.08。
- `blip()`:sine 880→1320Hz(0.06s 切),gain 0.14→0.001(0.16s),stop 0.2。
- `gunshot(heavy)`:noiseBuf→bandpass(heavy?750:1400, Q0.7)→gain(heavy?0.5:0.3 → 0.001,heavy 0.22s/轻 0.09s);heavy 加低频砰 sine 140→45Hz 0.12s,gain 0.4→0.001 0.15s。
- `explosion()`:sine 110→26Hz 0.7s,gain 0.7→0.001 0.8s;+noiseBuf→lowpass 900→120Hz 0.6s,gain 0.55→0.001 0.7s。
- `scheduleChord(ctx,freqs,when)`:每音 osc(f<100 用 triangle 否则 sine);peak=`(f<100?1.2:0.7)*(0.15/4音)`;0→peak 淡入 1.2s,维持到 when+3.2,淡出至 when+4.4;stop when+4.5。
- `scheduleDrums(when)`:120bpm 8 拍(0.5s/拍);偶数拍 kick(sine 105→42Hz 0.1s,gain 0.13→0.001 0.16s);第 2/6 拍 snare(noise bandpass 1700 Q0.9,gain 0.05 0.12s);每拍反拍 hat(noise highpass 6200,gain 0.028 0.05s,swing +0.02 隔拍)。

## main.ts 接线增量

- 开始按钮点击:`audio.start()`。
- 每帧:`audio.update(activeVehicle.speedKmh, driving, driving&&W?1:0)`;`setSiren(wanted.sirenLevel)`(下阶段);`setHorn(driving&&isDown('KeyF'))`;非驾驶 `setMovement(state, speed, dt)`;`setRain(weather.wetness)`。
- 边沿:上车 `door(false)+engineStart()`;下车 `door(true)+setHorn(false)`;进入 jump→`jump()`,离开 jump→`land(false)`;硬着陆→`land(true)`。
- 胎鸣:`setScreech(driving && Space && |kmh|>25 ? min(1,|kmh|/70) : 0)`。
- 行人被撞:`pedHit(true)`;驾车撞击 `iv>4 → crash(min(1, iv/22))`。
