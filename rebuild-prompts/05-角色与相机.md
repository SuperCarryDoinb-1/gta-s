# 05 · 玩家角色、步行控制器与第三人称相机

> 本阶段实现:`src/entities/Character.ts`、`src/gameplay/CharacterController.ts`、`src/entities/CameraRig.ts`,并在 main.ts 里临时接线可步行游览城市。

## 5.1 src/entities/Character.ts

常量:`RADIUS=0.35`、`HALF_HEIGHT=0.6`(胶囊总高 1.9m)、`KCC_OFFSET=0.02`、`CENTER_ABOVE_FEET=0.95`。
导出 `type HandPose = 'none'|'pistol'|'mg'|'grenade'`。

构造 `(scene, physics, spawn, personLib)`:spawn('Knight') 骨骼角色,root.y=-0.95 挂进胶囊中心系;kinematicPositionBased 刚体 + capsule(0.6,0.35);KCC:`offset 0.02`、`enableAutostep(0.65, 0.2, true)`、`enableSnapToGround(0.3)`、`maxSlopeClimbAngle 50°`、`minSlopeSlideAngle 55°`、`applyImpulsesToDynamicBodies(true)`;初始播 Idle。

公开:`mesh`、`body`、`collider`(readonly)。方法:
- `moveBy(desired)`:KCC computeColliderMovement → setNextKinematicTranslation(t+movement);更新 grounded。**必须在 physics.step() 之前**。
- `get grounded`;`getPosition(out)`;`getVisualPosition(out)`(mesh.position,插值后)。
- `setActive(active)`(封闭座舱:mesh 隐藏+collider 禁用);`setRiding(riding)`(敞座:mesh 保持可见,仅 collider 禁用);`get isRiding`。
- `forceY(y)`(楼梯高度场直设);`teleport(pos)`(重置 prev/curr/mesh);`setYaw(yaw)`。
- `beginStep()`(prev←curr)/`endStep()`(curr←刚体)。
- `setPose(pose)`;`playThrow()`(throwTimer=0.8,播 Throw once);`get rightHandAnchor`(handSlotR ?? mesh)。
- `aimArmsAt(leftTarget, rightTarget)` 手臂 IK:首次调用取骨骼 upperarm.l/lowerarm.l/upperarm.r/lowerarm.r,实测 `upperLen=肩肘距`、`lowerLen=upperLen*1.35`(默认 0.23/0.31);两段式:肩偏角 `β=acos(clamp((U²+d²-W²)/(2·U·d)))`,肘沉轴=`ikDir×Y_UP`,上臂朝 ikDir 绕该轴转 -β,前臂从新肘位直指目标;骨骼延伸方向为局部 +Y;方向长度钳位 0.05。
- `animate(dt, speed, grounded, swimming=false)`:swimBlend 过渡 `1-exp(-8*dt)`;剪辑优先级:骑乘→`Sit_Chair_Idle`(fade 0.15);throwTimer>0→递减不切;swimming→`Walking_A`(timeScale 1.6, fade 0.25);!grounded→`Jump_Idle`(fade 0.12);speed>6.5→`Running_A`;speed>0.1→`Walking_A`(timeScale max(0.9, speed/4));pose pistol/grenade→`1H_Ranged_Aiming`;mg→`2H_Ranged_Aiming`;否则 `Idle`。默认 fade 0.22。推进 mixer。
- `syncVisual(alpha)`:riding 时 return(外部贴装);mesh.position=lerp(prev,curr,alpha),`y -= swimBlend*0.42`;rotation.order='YXZ',`y = prevYaw+wrapAngle(currYaw-prevYaw)*alpha`,`x = -1.25*swimBlend`(游泳前倾)。

## 5.2 src/gameplay/CharacterController.ts

常量:`WALK_SPEED=5`、`RUN_SPEED=9`、`GRAVITY=-20`、`JUMP_SPEED=8`、`GROUND_STICK=-2`、`TURN_DAMPING=12`;游泳 `SWIM_SPEED=2.6`、`SWIM_FAST=4.2`、`SWIM_CENTER_Y=0.28`、`SWIM_ENTER_Y=0.45`。
`CharacterState = 'idle'|'walk'|'run'|'jump'|'swim'`。

构造 `(character, cameraRig, input, stairQuery)`;字段 `onHardLanding: ((speed)=>void)|null`;getter `state`、`speed`。

fixedUpdate(dt) 逻辑:
- WASD 相对相机:`moveDir = camForward*(W-S) + camRight*(D-A)` 归一;疾跑=Shift(左右任一)。
- 游泳判定:`chunkZone(round(x/96))==='ocean' && pos.y<0.45`;游泳时无重力不可跳,`velY=clamp((0.28-y)*3, -1.5, 1.5)`,速度 2.6/疾游 4.2。
- 跳跃:仅 `grounded && wasPressed('Space')` → velY=8;否则 `velY += GRAVITY*dt`,贴地时 velY=GROUND_STICK。
- 击退:kbX/kbZ 叠加进位移,每步乘 `exp(-2.2*dt)`,`|kbX|+|kbZ|>0.1` 才生效。
- 楼梯:`stairQuery(x, z, y-0.95)` 非 null 且 velY<=0.01 时,targetY=stairH+0.95,若 `y>targetY-1.2 && y<targetY+0.55` → `forceY(targetY)`、velY=0、onStairs=true。
- 硬着陆:进入本步竖直速度 impactV;`landed=grounded||onStairs`;`landed && !wasGrounded && impactV<-12` → `onHardLanding(-impactV)`。
- 转身:`targetYaw=atan2(-moveDir.x,-moveDir.z)`;`currentYaw += wrapAngle(targetYaw-currentYaw)*(1-exp(-12*dt))`;`character.setYaw`。
- 状态:`swim : !(grounded||onStairs)?'jump' : moving?(sprint?'run':'walk') : 'idle'`。
- `knock(vx,vz,vy)`:kbX=vx, kbZ=vz, velY=vy。`reset()`:全清零,state='idle'。

## 5.3 src/entities/CameraRig.ts

常量:`SENSITIVITY=0.0025`、`PITCH_MIN=-20°`、`PITCH_MAX=70°`、`DISTANCE=6`、`HEAD_OFFSET=1.5`、`PROBE_RADIUS=0.25`、`EXPAND_SPEED=8`、`CHASE_SHRINK_SPEED=22`、`CHASE_DISTANCE=6.5`、`CHASE_HEAD_OFFSET=1.3`、`CHASE_PITCH_MIN=-5°`、`CHASE_YAW_FOLLOW=5`、`CHASE_RECENTER=1.2`、`CHASE_DIST_PER_KMH=1/40`、`CHASE_DIST_MAX_EXTRA=2.5`。
初始:yaw=0, pitch=20°, currentDistance=6, zoom=zoomTarget=1。

构造 `(camera, physics, excludeCollider)`;`setExcludeCollider(c)`。

- `applyWheel(deltaY)`:`zoomTarget=clamp(zoomTarget*exp(deltaY*0.0011), 0.35, 2.8)`;`smoothZoom`:`zoom += (zoomTarget-zoom)*(1-exp(-10*dt))`;`zooming = |zoomTarget-zoom|>0.002`。
- `update(dt, feetPos, mouse)`(步行):`yaw -= mouse.x*0.0025`;pitch clamp(-20°,70°);`applyOrbit(dt, feet, 1.5, 6*zoom, snapIn=!zooming)`。
- `updateChase(dt, feet, headingYaw, speedKmh, mouse)`(驾驶):`chaseYawOffset -= mouse.x*0.0025` 后乘 `exp(-1.2*dt)`(自动回中);pitch clamp(-5°,70°);`targetYaw = headingYaw+π+chaseYawOffset`(看车尾);`yaw += wrapAngle(targetYaw-yaw)*(1-exp(-5*dt))`;`distance=(6.5+min(speedKmh/40,2.5))*zoom`;`applyOrbit(dt, feet, 1.3, distance, snapIn=false)`。
- applyOrbit(共享尾段):
```
target = feet + (0, headOffset, 0)
offsetDir = (sin(yaw)cos(pitch), sin(pitch), cos(yaw)cos(pitch))
hit = world.castShape(target, identity, offsetDir, Ball(0.25), 0, desired, ..., exclude, exclude.parent())
allowed = hit ? max(toi, 0.2) : desired
需要拉近: snapIn?瞬时:阻尼(1-exp(-22dt));拉远:阻尼(1-exp(-8dt))
camera.position = target + offsetDir*currentDistance;camera.lookAt(target)
```
- `getFlatForward(out)=(-sin yaw, 0, -cos yaw)`;`getFlatRight(out)=(cos yaw, 0, -sin yaw)`。
