## 7.1 src/entities/Pedestrians.ts

### 常量
`COUNT=26`(池)、`SPAWN_MIN=30`、`SPAWN_MAX=100`、`DESPAWN=130`、`WALK_MIN=1.1`、`WALK_MAX=1.9`、`RADIUS=0.3`、`HALF_CYL=0.6`、`ARRIVE_DIST=0.5`、`YAW_DAMPING=10`、`CENTER_ABOVE_FEET=0.9`、`FLEE_SPEED=4.5`、`FLEE_RADIUS=18`、`THREAT_CAR_SPEED=8`、`KNOCK_SPEED=6`、`DOWN_TIME=2.5`、`MAX_HP=100`、`KNOCK_DMG=55`、`DEAD_TIME=4.5`。
`CORNERS=[[1,1],[1,-1],[-1,-1],[-1,1]]`(人行道四角环路序)。
刚体:dynamic().lockRotations().linearDamping(0.2).angularDamping(1.5).ccd(true);capsule(0.6,0.3);模型 `ALL_PERSON_TYPES[i%5]`;血条 HealthBar3D 头顶 +2.05。
动画 LOD(平方距):<35² 全帧率、<75² 30Hz、更远 15Hz。重生高度 y=0.99。

### 状态机(state='walk'|'flee'|'down',每物理步 think)
```
回收:水平距玩家²>130² 或 y<-2.5 → respawn
down:downTimer 递减;到点后 dead→respawn,活人 horizSpeed<1.2→standUp
被撞倒:自身水平速度>6 → hp-=55;dead=hp<=0;state=down(timer dead?4.5:2.5);
  解锁全部旋转(真实翻滚);播 Death_A(once, fade 0.08);
  距玩家车<6 且玩家车速>5 → onHitByPlayerCar(x,z);dead 或 rand<0.6 → onDropMoney(x,z)
威胁:车距<18 且车速>8 且 closing=dot(carVel, 指向自己)/(…)>0.5 →
  flee(timer 1.5), threat=carPos+carVel*0.5
flee:timer 归零→rehome+walk;否则背向 threat 以 4.5 m/s 跑
停留:pause 递减,播 Idle
巡走:朝当前角落;dist<0.5 → pickNextTarget
```
`pickNextTarget`:roll<0.2 停留(pause=1+rand*3);roll<0.5 过马路(50% 沿 x:bx±=PITCH 跳对面角,否则沿 z);否则环路 corner=(corner+dir+4)%4。角落点=(bx+sx*10.5, 0, bz+sz*10.5)。
`rehome`:bx/bz=round(pos/32)*32,选最近角。
`respawn`:随机角度、距离 30+rand*70;`bx=max(round(x/32)*32, -224)`(夹回城市),bz 不夹;y=0.99;hp=100。
`standUp`:y+0.4、转正、锁旋转、rehome、播 Lie_StandUp(timeScale 1.4)。
`faceAndStride`:yaw 阻尼 10;speed>3 播 Running_A(1.15) 否则 Walking_A(max(0.8, speed/1.4))。

### 公开接口
- 回调:`onHitByPlayerCar(x,z)`、`onDropMoney(x,z)`。
- `beginStep(dt, playerPos, carPos, carVel)`(prev←curr+think,step 前)/`endStep()`/`syncVisual(alpha,dt)`(placeSkinnedRoot 插值+LOD 推进 mixer+血条,挂过伤才显示)。
- `forEachPed(cb)`(小地图)。
- `applyBulletDamage(body,dmg):boolean`:按刚体句柄找人;已死 true;归零→killPed(dead、down 4.5、解锁旋转、Death_A)+掉钱;未死非 down→从玩家方向惊逃(fleeTimer 3);命中返回 true(main 用于分流警察)。
- `panicAt(x,z,radius)`:半径内非 down 全部 flee(timer 2.5,threat=该点)。
- `applyExplosion(center,radius)`:半径内 `radialBlastImpulse`,`hp -= 130*(1-d/radius)`,归零 killPed+掉钱;再 `panicAt(center, radius*4)`。

## 7.2 src/entities/Traffic.ts

### 常量
`CAR_COUNT=6`、`CRUISE=8`、`TURN_CHANCE=0.35`、`RESPAWN_DIST=170`、`SPAWN_MIN=50`、`SPAWN_MAX=130`、`BRAKE_DIST=7`。
刚体 kinematicPositionBased;模型 `TRAFFIC_TYPES[i%6]`+colliderBoxes 双盒;灯:头灯 Standard{0xfff2cc, emissive, 0.3}@(±0.55,0.74,2.26),尾灯 {0x7a1414, emissive 0xff2222, 0.2}@(±0.55,0.74,-2.26),几何 Box(0.3,0.12,0.06);`setNight(n)`:头灯 0.3+2.4n、尾灯 0.2+1.6n。

### fixedUpdate(dt, playerPos, playerCarPos)
```
每车:prev←curr;距玩家²>170² → respawn(parked=false)
parked 跳过
blocked = isAhead(玩家)||isAhead(玩家车)||任一 isAhead(其他AI车)
targetSpeed = blocked?0:8;speed 阻尼逼近(1-exp(-4dt))
currYaw = advanceOnRoad(car, speed, dt, randomTurn)   // City 导出
setNextKinematicTranslation(x,0,z)+Rotation(yaw)
```
`isAhead`:前向投影 1≤forward≤7 且横向 |side|<2.2。
`randomTurn(dir)`:rand<0.35 → (dir+(rand<0.5?1:3))%4,否则直行。
`respawn`:随机 dir/角度/距离 50+rand*80;偶数向(沿z) `x=max(snapToRoad(px), -224+16)+LANE_X[dir]`, z=pz;奇数向 `x=max(px,-224)`, `z=snapToRoad(pz)+LANE_Z[dir]`;speed=8。

### 换车/剧情接口
- `swapWithPlayer(index, oldX, oldZ, oldYaw, oldType, leaveShell=true)`:返回 AI 车原 {x,z,yaw,type};leaveShell=false(玩家首次借壳)→AI 车易地 respawn 不留壳;true→AI 车换装为玩家旧车(位姿/车型,parked=true,speed=0)。
- `findNearest(pos, maxDist)`(平方比较,-1 表无)、`distanceTo(index,pos)`、`forEachCar(cb)`。
- `markCourier(playerPos)`:最近非停放 AI 车换装 `delivery`,返回索引;`courierState(index, outPos)`:写位置返回速度(parked 为 0)。
- `syncVisual(alpha)`:position lerp+yaw wrapAngle 插值。

## 7.3 main.ts 接线增量

fixedUpdate 顺序(在 character/vehicles beginStep 之后):取 `activeVehicle` 位置/速度 → `pedestrians.beginStep(dt, camTarget, carPos, carVel)` → `traffic.fixedUpdate(dt, camTarget, carPos)` → physics.step → 各 endStep。
临时接回调:`pedestrians.onHitByPlayerCar` → console(下阶段接通缉+音效);`onDropMoney` → console(下阶段接 Pickups)。
