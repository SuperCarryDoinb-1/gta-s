产品定位PRODUCT OVERVIEW

一句话定位

纯浏览器运行的 GTA 式开放世界原型:程序化城市里驾驶、犯罪、被通缉、赚钱,带六步主线剧情。零安装,点开即玩。

技术底座

Three.js 渲染 + Rapier(WASM)物理 + Vite/TypeScript。60Hz 固定步长物理,自适应像素比保帧率,全 CC0/CC-BY 开源素材。

体验支柱

① 驾驶手感(漂移/损伤/浮水)
② 追逐张力(视线遮挡的猫鼠博弈)
③ 漫游自由(昼夜天气 + 步行/车/摩托/船/坦克)

帧循环时序GAME LOOP

requestAnimationFrameEngine.tick — 帧耗时统计,均值 > 22ms 自动降像素比(最低 0.75)
↓累加器 ≥ 1/60s 时执行(可能 0~5 次)
fixedUpdate ×N(60Hz 物理步)陷地救援 → beginStep 记录 prev 位姿 → 行人/车流/警察 AI → 玩家输入 →
physics.step() → endStep 记录 curr 位姿
↓α = 累加器余量 / 步长

游戏逻辑详解GAME SYSTEMS

① 通缉系统(Wanted.ts — 全项目最大状态机)

星级触发(热度制,floor(heat) = 星)警方反应
1★开枪 / 撞行人 / 抢车警车路网追击(advanceOnRoad 选最朝向玩家的路口),近距切换直追模式,步行玩家被逼停
2★爆炸 / 杀警,或持续作恶累积警车到位后警察下车持枪围捕(SIEGE_DIST 14m),射击命中率随星级上升
3★热度上限 3.994 车 8 警全员出动,更狠的冲撞与更准的枪法
被看见 seen→ 脱离视线 6s → evading 星星闪烁→ 热度 -0.22/s → 归零收兵

核心机制:警察视线被建筑真实射线检测遮挡(castRay,排除自身车体),躲楼后即"隐身"。三条逃生路线成本递减风险递增:喷漆店 $200 即时洗白 → 下海(警察不下水) → 绕楼断视线(免费但要跑)。医院复活自动清星,失败不"死档"。

② 载具系统(Vehicle.ts — 一套代码四种载具)

载具获取方式spec 差异化
轿车(8 车型)主线夺回 / 街头按 E 抢基准手感;抢 AI 车即换壳(setCarType),车况回满
摩托主线终点取回最快最灵,压弯视觉,重撞甩人(-25HP);骑手 IK 双手贴把
快艇泊在近海,游过去上浮力弹簧+划水推进,水上 47km/h
坦克R 键空投(视线前方 12m,34m 高度落下)写实 Stridsvagn 103 模型,重车身
车况 100%撞击 Δv 扣减 → <50% 冒烟→ <25% 起火→ 0% 原地殉爆(波及 8m,可链式)

稳定性设计:实测双盒凸包碰撞 + NaN/坠落三道保险丝(自动复位到最后已知好位置)+ CCD 防穿地。开进深水不沉底——所有车都有兜底浮力,只是慢。

③ 生命值与失败循环(Health.ts)

五路伤害源警察子弹(驾车时车身挡 50%)· 爆炸冲击 · 车祸 Δv>10 · 摩托甩出 · 高空坠落 >12m/s
HP 0~100停火 6 秒后缓慢回血
HP=0 医院复活回出生点 · 扣 $100 · 通缉清零 · 强制下车

无死档惩罚:失败的代价是金钱与位置,不是进度——鼓励玩家大胆作死,这是 GTA 式沙盒的留存关键。

④ 世界生成(City.ts + ChunkManager.ts)

City.generateChunk(cx, cz) — 纯函数chunk 坐标 → mulberry32 确定性种子 → 3×3 街区数据(楼体/商店/塔楼/路灯/红绿灯/行道树/停靠车)
同一坐标永远生成同一批楼,无需存档
↓数据与渲染分离
ChunkManager — 按需实例化跟随玩家加载/卸载 chunk;万级体块合并进 InstancedMesh 控 draw call;碰撞体分帧构建防卡顿
分区:x 轴向西 = 城市 → 沙滩(棕榈/礁石) → 海洋(可游泳/开船) 路网:PITCH 32m 网格,右侧通行,车道偏移 ±2m 昼夜:光照/辉光/车灯/招牌联动;雨天:路面反光+雨声

⑤ AI 三兄弟:行人 · 车流 · 警察

系统行为模型与玩家的交互
Pedestrians(26 人)沿人行道拐角巡走,枪声/爆炸半径内惊逃四散可被子弹/车撞倒地(翻滚 ragdoll),死亡掉现金;超 130m 回收重生
Traffic(AI 车流)路网巡航:advanceOnRoad 共享行驶 + 跨路口 35% 随机转向;前方障碍刹车任意一辆都可按 E 抢走(玩家旧车留在原地成壳)
Wanted(警车 4 + 步警 8)同一套 advanceOnRoad,但跨路口选最朝向玩家的方向;近距离脱离路网直追视线检测 → 射击/逼停/围捕;对象池复用,超 170m 收兵

复用设计:三者共享路网常量与行驶算法(world/City),行人与警察共享骨骼动画工具(core/CharacterAnim)与血条(ui/HealthBar3D)——差异只在"选向策略"与"目标函数"。
